# Конкурентный анализ приложений-планировщиков 2025-2026

## Обзор для проекта "Планер" (Flutter)

Данный документ содержит комплексный анализ ведущих приложений в категориях todo, планировщиков и календарей. Цель -- определить лучшие практики дизайна и UX-паттерны для нашего Flutter-приложения "Планер".

---

## 1. TODO-ПРИЛОЖЕНИЯ

### 1.1 Todoist

**Визуальный стиль:** Чистый минимализм. Интерфейс намеренно "пустой" -- минимум визуального шума, максимум фокуса на задачах. Поляризующий дизайн: одним кажется спокойным, другим -- стерильным.

**Цветовая схема:** Преимущественно белый фон с красным акцентом (фирменный цвет). Приоритеты задач кодируются цветами (красный, оранжевый, синий, без цвета). Тёмная тема доступна.

**Ключевые UI-паттерны:**
- 6 точек рядом с задачей создают иллюзию "шершавой" поверхности для перетаскивания
- При наведении на задачу появляется курсор с четырьмя стрелками
- Изменение прозрачности при навигации между страницами
- Естественный язык при вводе задач (AI-парсинг дат и приоритетов)

**Премиальность:** Ощущение "премиума" достигается через безупречную типографику, обилие белого пространства и продуманные affordance-элементы для навигации.

**Уникальные фичи:**
- **Todoist Karma** -- система геймификации с очками за выполнение задач
- 5 уровней от "Новичок" до "Просветлённый"
- Стрики за последовательную продуктивность
- Визуализация прогресса линейным графиком
- Праздничные анимации при достижении нового уровня (можно отключить)
- AI-помощник разбивает большие задачи на подзадачи

**Онбординг:** Множество affordance-элементов направляют новых пользователей к ключевым функциям (drag-and-drop, проекты, фильтры).

**Завершение задач:** Чекбокс с анимацией заполнения. Система Karma даёт визуальную обратную связь -- цветные индикаторы по категориям на экране ежедневной статистики.

**Навигация:** Боковая панель (sidebar) на десктопе, bottom tab bar на мобильных.

### 1.2 TickTick

**Визуальный стиль:** Близок к Todoist по минимализму, но с дополнительной боковой панелью для встроенных инструментов продуктивности. При открытии задачи детали показываются в четвёртой колонке. Приложения ощущаются нативными для каждой платформы (Mac-версия отличается от Windows).

**Цветовая схема:** 40+ тем на выбор. Поддержка Liquid Glass на iOS 26. Привычки и счётчики поддерживают кастомные цвета -- можно задать единый цвет или индивидуальные для каждого типа контента. Новый "Modern" стиль календаря с улучшенной читаемостью.

**Ключевые UI-паттерны:**
- Живой Today-виджет -- чекбоксы работают прямо с виджета
- Матрица Эйзенхауэра как встроенный вид
- Календарный вид интегрирован в основное приложение
- Анимированный туториал при первом запуске

**Премиальность:** Ощущение "швейцарского ножа" -- всё в одном месте. Интеграция привычек, Pomodoro-таймера и календаря в одном приложении создаёт впечатление комплексного решения.

**Уникальные фичи:**
- Трекер привычек с богатой библиотекой
- Встроенный Pomodoro-таймер с настройкой длительности и автостарта
- Матрица Эйзенхауэра
- Белый шум / звуки природы при фокусировке

**Онбординг:** Отличный анимированный туториал, демонстрирующий ключевые возможности.

**Завершение задач:** Нажатие чекбокса отмечает задачу выполненной с возможностью мгновенной отмены.

**Навигация:** Bottom tab bar на мобильных, sidebar с дополнительными инструментами на десктопе.

### 1.3 Microsoft To-Do

**Визуальный стиль:** Чистый и дружелюбный интерфейс с Material-подобным дизайном. Глубокая интеграция с экосистемой Microsoft.

**Цветовая схема:** Фирменные цвета Microsoft. Фоновые изображения для списков. Тёмная тема.

**Ключевые UI-паттерны:**
- Функция "Мой день" (My Day) для ежедневного планирования
- Письма из Outlook автоматически становятся задачами
- Подсказки "Suggestions" для переноса задач в "Мой день"

**Премиальность:** Бесплатное приложение. Премиальность достигается через бесшовную интеграцию с Office 365.

**Уникальные фичи:**
- Email-to-task из Outlook
- "Мой день" с персонализированными предложениями
- Общие списки для совместной работы

**Навигация:** Sidebar слева (списки), основной контент справа.

### 1.4 Google Tasks

**Визуальный стиль:** Ультра-минимализм в стиле Material Design / Material You. Никаких излишеств -- чистые белые поверхности, стандартная типографика Google.

**Цветовая схема:** Material You с динамическими цветами из обоев на Android. Стандартные синие акценты Google.

**Ключевые UI-паттерны:**
- Интеграция в боковую панель Gmail, Google Docs, Drive
- Drag-and-drop из почты для создания задач
- Отдельный standalone-вид в браузере

**Премиальность:** Не претендует на премиальность. Ценность -- в интеграции с экосистемой Google.

**Уникальные фичи:**
- Задачи прямо из Gmail
- Синхронизация с Google Calendar
- Назначение задач в Google Docs (для бизнес-пользователей)

**Навигация:** Минимальная -- боковая панель в Gmail или standalone-вид.

### 1.5 Any.do

**Визуальный стиль:** Яркий, красочный интерфейс. Визуально более "весёлый" чем Todoist. Акцент на доступности для начинающих.

**Цветовая схема:** Яркие цвета, цветовые теги в платных планах. Кастомные визуальные темы.

**Ключевые UI-паттерны:**
- Множество визуальных раскладок: списки, календарь, доски (Kanban)
- Kanban-доска с колонками "To Do", "Doing", "Done"
- Левое боковое меню объединяет все основные элементы

**Премиальность:** Визуальное разнообразие раскладок. Приятный и "дружелюбный" интерфейс.

**Уникальные фичи:**
- Встроенный планировщик дня
- Kanban-доска
- Интеграция с WhatsApp для задач

**Навигация:** Левое боковое меню + нижние вкладки на мобильных.

### 1.6 Things 3

**Визуальный стиль:** Эталон дизайна среди todo-приложений. Увеличенное скругление углов окон, диалогов и задач. "Стеклянные" кнопки, которые отражают и преломляют окружение. Каждый пиксель тщательно продуман.

**Цветовая схема:** Фиксированная -- нет возможности менять темы или цвета. Используется мягкая палитра с акцентами: красные даты выделяются, звёздочки "Сегодня" подсвечиваются. Много белого пространства. Отменённые задачи -- крестик вместо галочки.

**Ключевые UI-паттерны:**
- При открытии задачи она плавно "разворачивается" в чистый белый лист
- Детали задачи спрятаны в углу, пока не нужны
- "Нет отвлечений -- только вы и ваши мысли"

**Премиальность:** Самое "премиальное" ощущение среди всех todo-приложений. Достигается через:
- Кастомный анимационный тулкит (не стандартные анимации платформы)
- "Маслянисто-плавные" (buttery smooth) анимации во всём приложении
- Идеальный баланс между деликатностью, утилитарностью и удовольствием от взаимодействия
- Безупречная работа на каждом устройстве Apple

**Уникальные фичи:**
- "Вечер" как отдельная секция (помимо "Сегодня")
- Headings внутри проектов для структурирования
- Magic Plus -- быстрое создание задачи из любого места

**Пустые состояния (Empty States):** Задача при открытии трансформируется в пустой белый лист -- "чистый лист бумаги для ваших мыслей". Минималистичные, воздушные пустые состояния.

**Анимации:** Всё анимировано кастомным движком. Разворачивающиеся анимации сохраняют контекст пользователя. Переходы между экранами плавные и осмысленные.

**Навигация:** Sidebar слева (Areas, Projects), основной контент справа. На iPhone -- полноэкранная навигация.

### 1.7 OmniFocus

**Визуальный стиль:** Функциональный, но визуально уступает Things 3 и Todoist. Поддержка тёмной и светлой тем. "Универсальный дизайн" обеспечивает единообразие на всех устройствах.

**Цветовая схема:** Фиолетовые акценты (фирменный цвет). Консервативная палитра.

**Ключевые UI-паттерны:**
- Expandable outlines -- раскрывающиеся списки, масштабируемые от простых до сложных групп действий
- Кастомные перспективы (Custom Perspectives) как фильтры-виды

**Премиальность:** Премиальная цена (от $9.99/месяц). Мощность и глубина настройки. Профессиональный инструмент для GTD-методологии.

**Уникальные фичи:**
- Полная реализация GTD (Getting Things Done) Дэвида Аллена
- Планируемый Kanban-вид
- Apple Intelligence интеграция (конец 2025)
- Omni Automation для скриптования

**Навигация:** Sidebar + toolbar сверху. Home Screen виджеты на iPhone.

## 2. ПРИЛОЖЕНИЯ-ПЛАНИРОВЩИКИ

### 2.1 Notion

**Визуальный стиль:** Минимализм "чистого холста". Чёрно-белая основа с намеренно нейтральной палитрой для создания спокойного рабочего пространства.

**Цветовая схема:** Стратегическое использование чёрного и белого создаёт чистую эстетику. Цвета применяются для визуальной ясности и интуитивной навигации. Нейтральные, приглушённые тона обеспечивают визуальную гармонию.

**Ключевые UI-паттерны:**
- Sidebar строится сверху вниз: имя workspace -> поиск -> навигация -> персональный контент
- Sidebar высотой 131px с 4 ключевыми элементами: Search, Notion AI, Home, Inbox
- Иконки последовательные: поисковая иконка в квадрате 22px, выровнена со всем остальным
- Дизайн с учётом мобильного поведения даже на десктопе -- "thumb-friendly" элементы

**Премиальность:** Ощущение "бесконечного холста" -- можно создать что угодно. Кастомные иконки, обложки страниц, эмодзи как иконки.

**Уникальные фичи:**
- Блочная система -- всё является блоком
- Множество видов одних и тех же данных (таблица, Kanban, календарь, список, галерея, timeline)
- Формулы и связи между базами данных
- Notion AI интегрирован в рабочий процесс

**Навигация:** Мощный sidebar слева. На мобильных -- скрываемый drawer.

---

### 2.2 Structured

**Визуальный стиль:** Визуальный таймлайн дня -- расписание представлено как вертикальная шкала времени. Чистый, ориентированный на фокус дизайн. Победитель App Store Awards (Tiimo, конкурент, получил iPhone App of the Year 2025).

**Цветовая схема:** Персонализация через цвета, иконки и раскладки. Задачи и категории окрашены в разные цвета для быстрого визуального различения.

**Ключевые UI-паттерны:**
- Расписание как визуальная временная шкала (timeline)
- Structured 4.0 (январь 2025): полный редизайн с новыми еженедельными и месячными видами
- Новый bottom tab bar: inbox, timeline views, AI, настройки
- Обновлённые анимированные иконки

**Премиальность:** "Превращает расписание в визуальную карту дня" -- уникальный подход к планированию.

**Уникальные фичи:**
- Визуальный таймлайн как основная метафора
- AI-планирование
- Inbox для быстрого сбора задач
- Интеграция с календарями

**Навигация:** Bottom tab bar (inbox, timeline, AI, settings) -- после редизайна 4.0.

### 2.3 Sorted3

**Визуальный стиль:** Apple-нативный дизайн. Чистый интерфейс в стиле iOS.

**Цветовая схема:** Стандартная iOS-палитра с акцентными цветами для категорий.

**Ключевые UI-паттерны:**
- Hyper-Scheduling -- автоматическое распределение задач по временной шкале
- Пользователь записывает задачи -> выделяет важные -> нажимает Auto-Schedule

**Премиальность:** "Первый в мире Hyper-Scheduler". Уникальная механика автопланирования.

**Уникальные фичи:**
- Auto-Schedule -- главная фишка
- Комбинация задач, событий и заметок в одном потоке
- Extra Large Widget на iPad
- Live Text, Quick Notes, Shortcuts

**Навигация:** Tab-based навигация в стиле iOS.

## 3. КАЛЕНДАРНЫЕ ПРИЛОЖЕНИЯ

### 3.1 Fantastical

**Визуальный стиль:** Изысканный (exquisite) интерфейс от Flexibits. Тёмная тема как основная -- повышает читаемость и визуальную привлекательность. Сбалансированный визуальный опыт на всех устройствах.

**Цветовая схема:** Цветовое кодирование событий по календарям. Индикаторы визуальной плотности. Нежные, не перегружающие цвета для dense-расписаний.

**Ключевые UI-паттерны:**
- Split-screen: сетка календаря + прокручиваемый таймлайн рядом
- DayTicker -- быстрый обзор дня в компактном виде
- Полноэкранные виды: день, неделя, месяц, квартал, год
- Тонкие анимации и цветовое кодирование делают плотные расписания визуально понятными

**Премиальность:** Justifies premium price через: полированный дизайн, интуитивную навигацию, мощные функции. "Календарь, без которого вы не сможете жить."

**Уникальные фичи:**
- Natural language input ("Обед с Машей в пятницу в 13:00")
- Объединение задач и событий
- Наборы календарей (Calendar Sets)
- Weather integration
- Видеозвонки прямо из событий

**Навигация:** Tab bar внизу на iOS. Sidebar + toolbar на macOS.

---

### 3.2 Calendly

**Визуальный стиль:** Модернистская типографика с геометрическими элементами. Система "текучих" (fluxional) форм и цветов, олицетворяющих гибкость.

**Цветовая схема:** Слои цветов и форм передают идею "пересечения расписаний". Каждая встреча визуально уникальна -- бесконечное разнообразие цветных форм в логотипе "C".

**Ключевые UI-паттерны:**
- Месячный вид + временные слоты на одном экране (редизайн 2025)
- Показываются только доступные слоты -- недоступные скрыты
- Упрощённый поток бронирования: выбор дня и времени на одной странице

**Премиальность:** Профессиональная брендированная страница бронирования. Ощущение "корпоративного" продукта.

**Уникальные фичи:**
- Flip-подход: вместо показа всего календаря -- только свободные слоты
- Branding страниц бронирования
- Round-robin распределение встреч
- Интеграция с видеозвонками

**Навигация:** Веб-ориентированный интерфейс с боковой навигацией.

---

### 3.3 Google Calendar

**Визуальный стиль:** Material Design / Material You. Чистый, функциональный дизайн без визуальных излишеств.

**Цветовая схема:** Material You -- динамические цвета из обоев устройства. Каждый календарь имеет свой цвет. Палитра из ~12 предустановленных цветов для событий.

**Ключевые UI-паттерны:**
- Виды: день, 3 дня, неделя, месяц
- FAB-кнопка (Floating Action Button) для быстрого создания события
- Swipe для навигации между днями/неделями

**Навигация:** Hamburger menu / drawer слева + FAB справа внизу.

---

### 3.4 Apple Calendar

**Визуальный стиль:** С iOS 26 -- **Liquid Glass**: полупрозрачные элементы с "оптическими свойствами стекла" (рефракция), реагирующие на движение, контент и ввод. Самый значительный визуальный редизайн Apple с 2013 года.

**Цветовая схема:** Системные цвета iOS. Динамическая адаптация к свету и контенту, имитирующая эффекты настоящего стекла. Скруглённые полупрозрачные элементы.

**Ключевые UI-паттерны:**
- iOS 26: создание событий из скриншотов (AI)
- Siri-интеграция
- Плотная интеграция с iCloud
- Shared calendars

**Премиальность:** Нативное ощущение на Apple-устройствах. Liquid Glass -- новый стандарт iOS-дизайна.

**Навигация:** Tab bar внизу на iOS. Toolbar сверху на macOS.

---

### 3.5 Timepage (Moleskine)

**Визуальный стиль:** **Самое красивое календарное приложение.** Создано "с нуля, чтобы быть максимально красивым при полной функциональности". Минималистичный дизайн -- весь контент на фоне одного цвета, фокус на информации.

**Цветовая схема:** **60 ручных тем** (Vivid Scarlet Red, Pastel Peach Orange, Hawking Black и др.). Каждая тема -- единый цветовой фон. Полный dark mode.

**Ключевые UI-паттерны:**
- Swipe-навигация создаёт ощущение настоящих бумажных страниц (как блокнот Moleskine)
- Нет центральной "колонки управления" -- весь экран это контент
- Полностью жестовое управление

**Премиальность:** Уровень Moleskine -- дизайн физического блокнота перенесён в цифровой мир. Демонстрируется на iPhone в Apple Store. Эталон дизайна в индустрии.

**Уникальные фичи:**
- "Тепловая карта" загруженности -- визуальное отображение плотности расписания
- Прогноз погоды интегрирован в день
- Travel time между событиями
- Насыщенность микроинтеракциями и восхитительными анимациями

**Пустые состояния:** Чистый цветной фон темы -- пустой день выглядит как чистая страница блокнота.

**Навигация:** Полностью жестовая (swipe). Минимум кнопок.

## 4. ТРЕНДЫ ДИЗАЙНА 2025-2026

### 4.1 Glassmorphism (возрождение)

- Вернулся благодаря Apple Liquid Glass (iOS 26, macOS)
- Матовое стекло, прозрачность, размытие фона, слоистые поверхности
- Современные GPU легко справляются с blur-эффектами на мобильных
- Применять осмысленно: оверлеи, плавающие карточки, элементы с фокусом
- Обязательно: сильный контраст текста, тестирование на реальных устройствах

### 4.2 Навигация

- **Bottom tab bar -- стандарт** для 3-5 основных действий
- Элементы управления в "зоне большого пальца"
- Touch targets: минимум 44x44px (рекомендуется 48x48px)
- Нечётное количество вкладок (3 или 5) создаёт лучший визуальный ритм
- Иконки + короткие текстовые метки (одно слово)
- Sidebar/Drawer -- для вторичных или редко используемых функций

### 4.3 Анимации и микроинтеракции

- Gartner: к концу 2025 75% клиентских приложений будут использовать микроинтеракции как стандарт
- Тактильная обратная связь (haptic) при нажатии кнопок
- Праздничные микро-анимации (confetti) после завершения задач
- Плавные переходы между экранами сохраняют контекст

### 4.4 Геймификация

- Очки и уровни (Todoist Karma)
- Стрики за последовательность
- Визуальный прогресс (графики, шкалы)
- Праздничные анимации при достижениях

## 5. РЕКОМЕНДАЦИИ ДЛЯ "ПЛАНЕРА"

### 5.1 Что взять от каждого приложения

| Приложение | Что перенять |
|---|---|
| **Things 3** | Кастомные "маслянистые" анимации, разворачивающиеся задачи, ощущение премиальности через внимание к деталям, пустые состояния как "чистый лист" |
| **Todoist** | Минималистичный дизайн, систему геймификации (Karma), AI-разбивку задач, natural language input |
| **TickTick** | Pomodoro-таймер, трекер привычек, 40+ тем, матрицу Эйзенхауэра, анимированный онбординг |
| **Timepage** | 60 тем (одноцветные фоны), жестовую навигацию, ощущение "бумажного блокнота", тепловую карту загруженности |
| **Fantastical** | Split-screen (календарь + таймлайн), DayTicker, natural language input для событий |
| **Structured** | Визуальный таймлайн дня, bottom tab bar (inbox/timeline/AI/settings) |
| **Notion** | Множество видов одних данных (список/Kanban/календарь), блочную систему |
| **Apple Calendar** | Liquid Glass эстетику (glassmorphism), создание событий из контекста |
| **Any.do** | Kanban-доску для задач, дружелюбный красочный интерфейс |
| **Sorted3** | Auto-Schedule -- автоматическое планирование дня |

### 5.2 Приоритетные решения для "Планера"

**Дизайн-система:**
1. **Основа: минимализм** (как Todoist/Things 3) -- много белого пространства, чистая типографика
2. **Glassmorphism-элементы** для карточек задач, оверлеев, floating-элементов (в духе Apple Liquid Glass)
3. **Кастомные анимации** -- не стандартные Flutter-анимации, а плавные переходы как в Things 3
4. **Акцентный цвет выбирается пользователем** (как в требованиях) -- минимум 12-15 цветов на выбор

**Навигация:**
1. **Bottom tab bar с 4-5 вкладками** (уже в требованиях): Сегодня, Календарь, Задачи, (Привычки?), Настройки
2. Touch targets 48x48px
3. Иконки + текстовые метки

**Завершение задач:**
1. Анимированный чекбокс (как Things 3 -- плавное заполнение)
2. Haptic feedback (вибрация) при завершении
3. Опциональные праздничные эффекты (confetti/particles) при завершении всех задач дня
4. Streak-система за последовательное выполнение

**Онбординг:**
1. 3-5 экранов с анимированными иллюстрациями
2. Демонстрация ключевых фич (как TickTick)
3. Выбор акцентного цвета и темы на этапе онбординга
4. Быстрый старт: создание первой задачи прямо в онбординге

**Пустые состояния:**
1. Вдохновляющие иллюстрации (не скучный текст "Нет задач")
2. CTA-кнопка "Создать задачу" прямо в пустом состоянии
3. Мотивационные фразы на русском

**Уникальные фичи для дифференциации:**
1. **Визуальный таймлайн дня** (как Structured) -- ключевая метафора
2. **Тепловая карта загруженности недели/месяца** (как Timepage)
3. **Smart Auto-Schedule** (как Sorted3) -- ИИ раскидывает задачи по свободным слотам
4. **Виджеты трёх размеров** (уже в требованиях) -- live-виджеты с рабочими чекбоксами (как TickTick)
5. **Шкала прогресса** (уже в требованиях) -- визуализация как в Todoist Karma

### 5.3 Чего избегать

- **Перегрузка функциями** (OmniFocus): не делать "всё для всех" -- фокус на core experience
- **Стерильный дизайн** (Google Tasks): слишком простой интерфейс не запоминается
- **Негибкий дизайн** (Things 3): отсутствие тем и кастомизации -- пользователи хотят "свой" дизайн
- **Устаревший интерфейс** (OmniFocus): визуальная свежесть критична для привлечения
- **Сложный онбординг**: максимум 3-5 экранов, без перегрузки информацией
